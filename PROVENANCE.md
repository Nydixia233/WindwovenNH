# Source provenance

- WindwovenNH is the new name for the original Trailcloth project. Release numbering restarted at WindwovenNH 0.1.0, with the Trailcloth 0.2.2 solver unchanged. This repository was initialized independently; no WaveyCapes, Wavey Capes (Legacy), or other local port code, assets, motion traces, or build output was imported. There is no runtime dependency on a cape distribution service.
- Scope and testing requirements reuse only behavioral and compatibility findings. The cloth solver uses the published position-based dynamics technique of Müller, Heidelberger, Hennix and Ratcliff (2006/2007), DOI `10.1016/j.jvcir.2007.01.005`. No implementation or media from the paper is included.
- Wrapper files and daemon toolchain metadata originate from `GTNewHorizons/ExampleMod1.7.10` at `bd8e4160b677466de3cfff2c4011a3806fa74942`; the original MIT notice is in `licenses/GTNH-ExampleMod-MIT.txt`. The Gradle wrapper remains Apache-2.0 (see `licenses/Gradle-Wrapper-Apache-2.0.txt`), and its properties pin the official distribution SHA-256. The build uses GTNHGradle 2.0.34. Forge and UniMixins (including Mixins and MixinExtras) are supplied separately. Nothing from the game, modpack, or shaders is bundled.
- The 0.2.0 reference is an independently implemented double-precision simulator using published compliant position constraints (Macklin, Müller and Chentanez, *XPBD*, 2016), area-lumped mass and geometric drag. Fitting uses original synthetic scenarios. The 0.2.0 comparison binary is Trailcloth’s own 0.1.4; 0.2.1 compares against Trailcloth 0.2.0 and 0.2.2 against Trailcloth 0.2.1. The head-contact proxy, wake recovery and fixtures are original changes. No third-party source, assets, reference meshes or motion captures are incorporated in the mod.
- The production mod renders cape textures that the installed game already selected. The QA fixture generates its own asymmetric atlas at runtime. The installed GregTech cape is referenced only for runtime visual testing, not copied into a release asset.
- Development and documentation were assisted by generative AI. WindwovenNH is not an official Minecraft, GTNH, or WaveyCapes release.
